## Engineering Focus

我关注的不只是 LLM API 调用，而是 AI 应用中可验证的工程过程：

- **Evidence-driven Decisions:** 用确定性分析提供事实，由 LLM 基于证据作出决策。
- **Reliability & Failure Analysis:** 关注工具调用边界、输入校验、错误处理与可追溯性。
- **Evaluation:** 通过小型可复现实验检验 RAG 检索行为，而非仅凭生成结果判断质量。
